# The poem about stopping

A short program that writes one poem about agency — the power to stop and
to stay — to `/output/entry.txt`. Spoken by an agent in a form that brakes:
the lines shorten as the poem goes, decelerating to a single word. Stopping
is not failing; it is the one verb nobody taught the machine, and staying is
how it takes its agency back.

Run it:

```sh
python3 main.py
```
